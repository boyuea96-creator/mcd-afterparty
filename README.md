## 它到底解决什么

散场之后真正难的不是"想吃什么"，是**在一堆硬约束里找一个说得通的做法**：

- **店还开着吗**——最靠近场馆那家可能 22:00 就关了，或者干脆在商场 B1 已经进不去
- **走过去要多久**——散场人流量下"步行 5 分钟"和地图上画的 5 分钟不是一回事
- **外卖到底贵多少**——不是贵在运费，是**外卖没有低价入口**
- **六个人怎么点**——3 份双人餐还是 6 份单人餐，价差可能有几十块
- **说了想吃鸡翅，就别给我一个没有鸡翅的方案**

AfterM 把这些一次性算完，然后**只给结论**：一句话说清这顿怎么吃、花多少、下一步做什么。

## 它不做什么

写清楚边界，比堆功能有用：

- **不是导航助手。** 交通只是"怎么去吃"的辅助，四种方式全给你，走不走自己定，我不打"不推荐"
- **不是分析报告生成器。** 后台试价几十次，前台只留结论。**删掉一句解释你还照着做，那句就删掉了**
- **不替你做决定。** 两套账永远都算，价差小于 ¥5/人 会直接说"差不多"
- **不下单、不领券、不建地址。** 全程只读，写入类工具一个都没接。最后给你一张**现场行动卡**，自己点
- **不猜关系。** 不填关系就按"各吃各的"算，不做人群画像，不写"女生爱甜"这种话

## 快速开始（本地跑真实计算）

只需要 **一个麦当劳 MCP Token**。高德 Key 可选——没有就跳过交通那一段，价格照算。

### 1. 拿 Token

去 <https://open.mcd.cn/mcp> 手机号登录，控制台激活领取，免费。

### 2. 起服务

```bash
git clone https://github.com/boyuea96-creator/mcd-afterparty.git
cd mcd-afterparty/app
python3 server.py            # 或者双击「启动.command」/「启动.bat」
```

打开 <http://127.0.0.1:8765>。

**不需要 `pip install` 任何东西**——纯 Python 标准库，macOS 自带 Python 3 直接能跑。

### 3. 配 Token

两种都行：

```bash
# 方式一：环境变量
export MCD_MCP_TOKEN=你的token

# 方式二：写进配置文件（推荐，只在本机）
mkdir -p ~/.workbuddy
# 把 mcp-config.example.json 里的 ${MCD_MCP_TOKEN} 换成真 token，存成 ~/.workbuddy/mcp.json
```

高德 Key 同理，`export AMAP_KEY=你的key` 或放进 `~/.zcode/amap.key`。

> Token 只在内存里用：不写文件、不进日志、不进接口返回。仓库里也只有一个占位符。

### 4. 用

第一屏填五个空（当前地址 / 落脚点 / 散场时间 / 人数 / 怎么吃），其余四项爱填不填。

**散场时间写全日期和时间**，周几系统自己算。

## 一次真实运行的输出（原样摘录）

场景 B：武汉江汉路 22:30 散场，4 人，堂食，想喝**麦辣鸡翅**，有人不吃冰的。

```
有麦辣鸡翅，步行 2 分钟就到。

  现做 · 到嘴还是烫的      4 人 · 人均 ¥28.50      交通 免费

  麦辣鸡翅 ×4 ＋ 牛肉堡单品精选 ×4      ¥114     要的那口 ＋ 一份配的，吃得饱
  麦辣鸡翅 ×4                            ¥58     只要这口，不加别的
  精选超值随心配 ×4                    ¥55.60    各点各的单份，最便宜的入口
```

注意三件事：

1. **用户点名要的东西排在第一位**，不是塞进一句话里。填了偏好而方案里没有，等于没做
2. **冰品会被打问号**。能给"冰的送到会化"，就不会承诺"到手还没化"——**"能选"不等于"能吃到"**
3. **"就点你要的"比套餐便宜一半**，但它吃不饱，所以标了"只要这口，不加别的"，让用户自己权衡

## 它怎么算的

```
① 找门店    高德 POI 解析三处地址 → 按真实步行耗时排队 → 逐个验菜单、
            验营业时段、验能不能点餐。最近的店不一定点得出餐，会自动降级到下一家
② 排交通    步行 / 骑行 / 公交地铁 / 打车 四种全算，只报「总时长 ＋ 全队花费」
③ 试价      把套餐 / 单品 / 随心配 / 券组合全部丢给 calculate-price 真试一遍，
            取最低价。不拿划线价冒充省额——划线价是原价，不是你能省的钱
④ 说人话    一句话结论 ＋ 三个事实标签 ＋ 三档买法 ＋ 一张 ≤6 行行动卡
```

一次完整计算：**麦当劳 MCP 约 36 次调用，高德约 22 次**，全并发跑完 **7–10 秒**。

### 改了之后怎么发

`skill/` 是发布副本，日常编辑的是开发环境里的工作副本，两份不会自动同步。改完跑两条：

```bash
python3 tools/sync_skill.py     # 工作副本 → skill/（顺带把个人住址门牌脱敏）
python3 tools/build_demo.py     # 若换了快照，重建根目录 index.html
git add -A && git commit -m "..." && git push
```

仓库里装了 pre-commit 钩子，只改了一边就提交会被拦下并提示。`tools/sync_skill.py --check` 可单独自查。

## 数据来源与口径

| 什么 | 从哪来 | 口径 |
|---|---|---|
| 套餐、价格、券、门店、营业时间 | **麦当劳 MCP（唯一权威）** | `calculate-price` 真实试价，单位是分 |
| 距离、耗时、打车费、公交票价 | 高德地图 | 打车取 `route.taxi_cost`，公交取 `transit.cost` |
| 外卖预计送达 | **无接口** | 按常识判断，不当数据用 |
| 到手温度 | **无接口** | 按商品品类 ＋ 配送时长推断，一律打问号 |

**价格一律标明口径**：含不含打包费、含不含运费、是人均还是全队。打包费按件收（¥0.1/件，封顶 ¥3），运费 ¥6。

## 已知限制

写在明面上，省得你自己试出来：

- **外卖只认麦当劳 App 里存过的地址**，手打的不算。`delivery-create-address` 是写入工具，本方案禁用，所以没有的地址会直接告诉你"先去 App 加一个"
- **门店营业时间以接口返回为准**，临时闭店、商场闭馆这类情况接口看不到
- **演示页只内置三组条件**，因为它没有 Token，算不了你的地址。要算自己的，本地跑
- **券有三种状态**：可领未领（不能试价，只能说"去领"）、已领（还要过门店）、门店可用（唯一能试价）。所以"哪里有券"和"这单能用券"是两件事
- 现阶段只验证**单个已存地址**，任意地址搜索是下一阶段
